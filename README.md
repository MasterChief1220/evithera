# Evithera

Website von [evithera.de](https://evithera.de): Evidenz in der Therapie – Wissen, was hilft.

Evithera ist eine App für Physiotherapeut:innen, Evimove die für Trainer:innen: Tests jedes Mal gleich messen, Übungen begleiten und im Verlauf zeigen, ob sie wirken. Stand November 2026: Konzept und Prototyp.

Statische Seite ohne Build-Schritt, Schriften lokal (Inter, Syne; SIL Open Font License), keine Cookies, kein Tracking. Bereitgestellt über GitHub Pages.
