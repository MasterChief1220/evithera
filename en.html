Evidence in therapy
Know what helps

Evithera is an app for physiotherapists. It helps them run tests the same way every time, evaluate the results and show over time whether the exercises work.

The idea

Measure the same way, treat individually

Because every test runs the same way, the values can be compared – between sessions, patients and practices. That creates good data. Treatment stays individual; from many courses the app learns which exercise works best for which finding, and so makes better suggestions for everyone.

Status

Where the project stands

  • A knowledge base of studies and guidelines is growing; every entry has a source. The first test field is the foot (flexible flatfoot, splayfoot).
  • Our own AI computer translates tests from the literature into precise measurement procedures.
  • A first movement measurement app runs as a prototype; a test run with athletes of an athletics club is planned.
